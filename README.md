# LivingStones Association website

Static site for www.livingstones-association.org (moved off Wix in November 2026).

- Edit page bodies in `_src/pages/*.html` and the shared header/footer in `_src/layout.html`.
- Rebuild with `python3 _src/build.py`. This writes the `*/index.html` files and `sitemap.xml`.
- Styles: `assets/css/site.css`. Images: `assets/img/`.
- Hosting: GitHub Pages, deployed from the `main` branch.

**Do not rename these paths.** The QR codes on the memorials in Moldova link to them:
`/cepeleuti-memorial`, `/cupcini-memorial`, `/cupcini-righteous-amongst-the-nations`.

Forms (contact, newsletter, donation notice) go through FormSubmit to info@livingstones-association.org.
